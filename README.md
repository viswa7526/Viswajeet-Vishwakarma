# Viswajeet Vishwakarma — Portfolio

## Files
- `index.html` — page content and SEO metadata
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation, typing effect, reveal animations and scroll progress

## Before publishing
1. Replace `YOUR-DOMAIN.com` in `index.html` with your real domain (canonical URL, Open Graph URL and JSON-LD URL).
2. Replace `YOUR-EMAIL@example.com` with an email address you want public.
3. Add your real LinkedIn profile URL.
4. Replace sample projects and skill tags with genuine information. Remove anything that is not accurate.
5. Add a real profile photo if you want one; the current avatar is a designed initial, not a photograph.
6. Create `robots.txt` and `sitemap.xml` using your final domain.
7. Publish over HTTPS, then verify the domain in Google Search Console and submit the sitemap.

## Run locally
Open `index.html` in a browser. No build tools are required.

## SEO reality
A website cannot guarantee that Google will show your name first. A unique domain, accurate public profile information, useful original content, links from your GitHub/LinkedIn profiles, and Google indexing can improve the chance. Ranking depends on competition and Google's systems, and may take time.
